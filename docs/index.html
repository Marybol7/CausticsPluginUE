LiquidFX

Plugin modular para la simulación visual de cáusticas y efectos líquidos en Unreal Engine.

El proyecto combina materiales, shaders, postprocesado, Blueprint e interacción básica para crear agua creíble en tiempo real sin recurrir a una simulación física completa.

Descripción

Sobre el proyecto

Objetivo

LiquidFX nace como una herramienta reutilizable para integrar efectos líquidos en escenas 3D. El objetivo principal es conseguir un equilibrio entre calidad visual, rendimiento y facilidad de configuración.

Enfoque

En lugar de crear una simulación física completa, el sistema utiliza aproximaciones visuales propias de tiempo real: normales animadas, World Position Offset, texturas de cáusticas, depth fade, postprocesado y efectos dinámicos.

Arquitectura

Módulos principales

01

Material base

Agua parametrizable con normales animadas, opacidad, tiling e intensidad ajustable.

02

Oleaje

Movimiento mediante onda senoidal, ondas de Gerstner y combinación con ruido.

03

Cáusticas

Patrones de luz animados aplicados mediante spotlight y material de cáusticas.

04

Profundidad

Depth fade, cambio de color según profundidad e integración con el entorno.

05

Underwater

Escena submarina con partículas, distorsión visual y oscurecimiento progresivo.

06

Interacción

Foam, ripples, salpicaduras y base de flotación simplificada para objetos.
